## Реализовано

- На всех семи страницах CSP в HTML до загрузки ресурсов. Разрешены только собственные скрипты; встроенный JavaScript и eval не разрешены. Стили — собственные и Google Fonts, шрифты — собственные и fonts.gstatic.com. Изображения и видео — собственные. `connect-src`, `object-src`, `worker-src`, `manifest-src`, `base-uri`, `form-action` запрещены. `frame-src` запрещён на шести страницах; на странице Linkwood допускается только https://www.youtube-nocookie.com для выбранного пользователем плеера по нажатию.
- Referrer policy `strict-origin-when-cross-origin`: при переходе на другой HTTPS-сайт полный путь и параметры текущей страницы не передаются.
- Встроенный стиль noscript заменён внешним CSS, чтобы строгая CSP не ломала уведомление.
- Код языка проверяется по списку en/de/uk, включая значения URL и localStorage. Ключи прототипа объекта (`__proto__`, `constructor`, `toString` и др.) больше не принимаются как словари.
- Текст при построении HTML экранируется; форматированные переводы допускают только точные теги br и em без атрибутов. Изображения карточек ограничены локальными JPG-именами.
- Пользовательский текст формы остаётся текстом в локальном Blob-файле. Сетевой отправки нет. При отказе JavaScript обычную отправку формы блокирует CSP. После подключения реального приёма заявок политика и серверная валидация должны быть пересмотрены.
- `apply-security.cjs` применяет политики ко всем страницам и синхронизирует site/dist. `finalize-multipage.cjs` вызывает его после пересборки, чтобы защита сохранялась.

## Проверено

- HTTPS главной страницы: HTTP 200, HSTS `max-age=31556952`. В настройках GitHub Pages Enforce HTTPS включён и обязателен для стандартного домена.
- До изменения HTTP-ответ не содержал CSP, X-Frame-Options, X-Content-Type-Options и Referrer-Policy. HTML CSP и referrer meta добавлены; они не являются новыми серверными HTTP-заголовками.
- `test-security.cjs`: посторонние значения языка, сохранение br/em и экранирование XSS-разметки, наличие строгой CSP на всех страницах, отсутствие inline-скриптов и обработчиков, отсутствие исполняемых элементов в предоставленном SVG.
- `test-multipage.cjs`, `test-multipage-gate.cjs` и синтаксическая проверка JS прошли.
- Изолированная локальная страница с той же CSP подтвердила реальную браузерную блокировку eval, inline script, data-script, fetch, iframe и отправки формы. Это негативные тесты в локальном окружении, а не атаки на чужие сайты. Тестовые файлы не включены в публичный сайт.
- Проверены загрузка шрифтов, переключение языка, страница с `lang=__proto__`, семь тем дегустаций и отсутствие ошибок JavaScript в обычных страницах.
- В локальной папке github-pages не найдены .env, БД, SQL, ключевые файлы и совпадения с ограниченным набором сигнатур приватных ключей/GitHub/OpenAI-токенов. Это не полный аудит истории публичного репозитория и не гарантия отсутствия всех видов секретов.

## Ограничения GitHub Pages

HTTP-заголовки сервера в этом способе размещения не управляются файлами .htaccess или Netlify _headers. Такие файлы не добавлялись как якобы работающая защита.

`frame-ancestors` и X-Frame-Options через HTML meta не работают. Поэтому защита от встраивания самого сайта в чужой iframe не заявляется; `frame-src 'none'` запрещает только iframe внутри нашего сайта. X-Content-Type-Options, Permissions-Policy, COOP и полный CSP HTTP header остаются задачей будущего хостинга/CDN с управлением заголовками. HSTS уже предоставляет GitHub.

Шрифты пока загружаются с Google Fonts — это два явно разрешённых сторонних источника. CSP не заменяет проверку собственного кода, защиту GitHub-аккаунта, контроль публикаций или серверную безопасность будущего API. Заставка 18+ остаётся пользовательским подтверждением, а не проверкой документов и не механизмом авторизации.
